# 🎮 Pixeldex - Beginner Pokémon Dev Project
> Fork this repo to work on the issues on your own and practice git commands and moving in the terminal. 
## 📖 Description
A simple, beginner-friendly Pokémon-inspired "Pixeldex" application designed as an introduction to software development. This project focuses on teaching terminal navigation, Git fundamentals, and vanilla web development.

## 🛠️ Tech Stack
- **Frontend:** Vanilla HTML, CSS, JavaScript
- **Styling:** Pokémon-inspired color palette (maintained in a clean, readable CSS file)
- **Data Source:** [PokeAPI](https://pokeapi.co/) (to be integrated step-by-step)
- **Local Server:** Python (`python -m http.server`) or VS Code Live Server

## 🚀 Getting Started
1. Clone this repository
2. Open the project in your terminal
3. Start a local server:
   - Python: `python -m http.server 8000`
   - Or use VS Code's "Live Server" extension
4. Open `http://localhost:8000` (or `8080`/`5500` depending on your setup) in your browser

## 🎯 Learning Objectives
- Navigate the terminal confidently
- Understand core Git workflows (init, add, commit, branch, merge)
- Build a static web app with vanilla HTML/CSS/JS
- Fetch and display data from a REST API
- Practice feature development through Git issues

## 🐛 Git Workflow & Issues
This project uses GitHub Issues to guide learning. Each issue represents a small, achievable task or feature. Students will:
- Create branches for each issue
- Implement changes locally
- Commit with clear messages
- Open pull requests for review

Keep the app simple. Focus on fundamentals over complexity.
